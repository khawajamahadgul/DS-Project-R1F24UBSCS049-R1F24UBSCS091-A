Music Playlist Management System

## Selected Data Structure
Doubly Linked List

## Main Features
- Add songs to the playlist (at end or after current song)
- Remove songs by name
- Play next and previous songs
- Play a specific song directly
- Stop playback
- Search songs by title
- Display full playlist with current song highlighted
- Reverse the entire playlist
- Repeat modes (Repeat All / Repeat One / Off)

## How to Run
1. Download `MusicPlaylist.cpp`
2. Open in Dev C++ or any C++ compiler
3. Compile and run
4. Use the menu numbers to navigate features
